# Global Marketing Campaign Dashboard

## Project Overview

This project was developed to analyze marketing campaign performance across countries, regions, products, and channels using Power BI.

The dashboard enables business users to monitor advertising effectiveness, campaign profitability, budget utilization, and return on advertising spend (ROAS).

---

## Business Objectives

- Monitor campaign performance
- Analyze sales and marketing spend
- Measure ROAS effectiveness
- Track CTR and CPC performance
- Compare country and regional performance
- Evaluate product profitability
- Support budget optimization decisions
